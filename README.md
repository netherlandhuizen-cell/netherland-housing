# NetherlandHuizen - Real-Time Housing Map & Listings

Live interactive map and rental tracker for properties across Amsterdam, Rotterdam, Utrecht, Delft, and the Netherlands.

## Features
- **Interactive Map**: Built with Leaflet.js and Esri World Street Map (zero watermarks, fast CloudFront CDN).
- **Direct Supabase Integration**: Real-time property fetching via Supabase REST API.
- **Commute Time Badges**: Bike commute estimations to central stations calculated with OSRM and Geopy.
- **Filtering & Search**: Instant filtering by city, price range, and search query.
- **Responsive Dark Theme**: Modern glassmorphic dark design.

## Deployment
Deployed seamlessly on [Vercel](https://vercel.com).
